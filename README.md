# Радни сати — Android апликација

Тамна апликација за Samsung Galaxy A56 за локалну евиденцију радних смјена.

- Календар свих дана изабраног мјесеца.
- Унос почетка и краја смјене, укључујући смјене које прелазе поноћ.
- Ноћни рад од 22:00 до 06:00; остало је дневни рад.
- Мјесечни збир дневних, ноћних и укупних сати.
- Напомена за сваки дан, са могућношћу измјене и брисања.
- Локално чување података на телефону.
- Тамна тема и анимирани пјешчани сат.

## APK преко GitHub Actions

Workflow је у `.github/workflows/build.yml`. Када се пројекат налази у репозиторијуму, отвори картицу Actions, изабери `Build RadniSati APK`, па преузми артефакт `RadniSati-APK` након успјешне изградње.

APK није унапред уграђен у овај ZIP; GitHub Actions га прави током workflow-а.
